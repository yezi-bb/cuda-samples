# 第 6 周：卷积、排序与蒙特卡洛

继续 `cpp/2_Concepts_and_Techniques/`。本周把「共享内存分块」「排序」「随机数库」三条线分开，避免和上周的原语混在一起。

## 周一：可分离卷积（精读）

**路径**：`convolutionSeparable`、`convolutionTexture`

**做**

- 精读 `convolutionSeparable`：二维高斯卷积拆成行卷积和列卷积，各看一次共享内存装载（含 halo）
- 对照 `convolutionTexture`：同一滤波器走纹理采样。README 写明它用来和可分离版本比性能
- 两份都运行，把耗时抄到同一行笔记里，不要求你优化

**想清楚**

1. 可分离为什么把 `K*K` 次乘加变成 `2*K` 次？
2. halo 是什么，不加载它会在 tile 边界产生什么错误？
3. 纹理版省下的是显式边界处理还是共享内存管理？

**完成标准**：能画出一个 tile 的有效区和 halo 区。

## 周二：排序网络与基数排序（精读 sortingNetworks）

**路径**：`sortingNetworks`、`radixSortThrust`

**做**

- `sortingNetworks`：双调排序和奇偶归并。README 说明它们适合短到中等长度的一批键值，不是大数组的最优解
- 看比较器如何映射到线程，以及 batch 中多个短数组如何并行
- `radixSortThrust`：调用 Thrust 的基数排序。分清哪些代码是样例自己的，哪些是库调用

**想清楚**

1. 排序网络为什么几乎没有数据相关分支？
2. 什么规模下你会放弃排序网络，改用基数排序？
3. Thrust 样例的宿主代码还要不要自己写 kernel launch？

**完成标准**：能说出两种排序的适用长度，并指出 Thrust 版的入口函数。

## 周三：cuRAND 的四种估 π（精读一种，对照三种）

**路径**：`MC_EstimatePiInlineP`、`MC_EstimatePiInlineQ`、`MC_EstimatePiP`、`MC_EstimatePiQ`

**做**

- 先读四份 README 的标题差：inline/batch，PRNG/QRNG
- 精读 `MC_EstimatePiP`（批处理伪随机）：主机如何生成随机数、如何把点是否落在圆内变成归约
- 其余三份只记录：随机数在主机生成还是在设备上 inline、用的是伪随机还是拟随机

**想清楚**

1. 蒙特卡洛估 π 的数学是什么（单位正方形内落在四分之一圆中的比例）？
2. 拟随机（低差异序列）相对伪随机，样例期望看到什么差异？
3. inline 生成省掉了哪一块全局内存流量？

**完成标准**：四格对照表填完。不必四份都编译。
